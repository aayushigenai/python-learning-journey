# Types of Operators

## Topics Covered

* Arithmetic Operators

---

## 1. Arithmetic Operators

Used to perform mathematical calculations.

| Operator | Meaning             | Example |
| -------- | ------------------- | ------- |
| +        | Addition            | a + b   |
| -        | Subtraction         | a - b   |
| *        | Multiplication      | a * b   |
| /        | Division            | a / b   |
| %        | Modulus (Remainder) | a % b   |
| **       | Exponent (Power)    | a ** b  |

### Practiced

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Power Operator

---

## 2. Relational Operators

Used to compare values and return either `True` or `False`.

| Operator | Meaning                  |
| -------- | ------------------------ |
| ==       | Equal to                 |
| !=       | Not equal to             |
| >        | Greater than             |
| >=       | Greater than or equal to |
| <        | Less than                |
| <=       | Less than or equal to    |

### Practiced

* Comparing two numbers
* Understanding boolean results

---

## 3. Assignment Operators

Used to assign or update variable values.

| Operator | Example |
| -------- | ------- |
| =        | a = 10  |
| +=       | a += 5  |
| -=       | a -= 5  |
| *=       | a *= 10 |
| /=       | a /= 5  |
| **=      | a **= 2 |

### Practiced

* Updating variables using assignment operators

---

## 4. Logical Operators

Used to combine multiple conditions.

### NOT Operator

* Reverses a boolean value.

Example:

* not True → False
* not False → True

### AND Operator

Returns `True` only when all conditions are true.

Example:

* True and True → True
* True and False → False

### OR Operator

Returns `True` if at least one condition is true.

Example:

* True or False → True
* False or False → False

---

## Key Learnings

* Arithmetic operators perform calculations.
* Relational operators return boolean values.
* Assignment operators update existing variable values.
* Logical operators help combine conditions.
* Python uses `True` and `False` for boolean results.
