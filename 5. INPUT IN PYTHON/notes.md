## 1. input() Function

Used to take input from the user through the keyboard.

### Example

```python
input("What is your name?")
```

### Key Point

* Python waits for the user to enter a value.
* Input is always received as a string.

---

## 2. Input in Variables

Input can be stored inside variables and used later.

### Example

```python
name = input("What is your name?")

print(name)
```

### Practiced

* Taking user input
* Storing values in variables
* Displaying user input

---

## 3. Type Casting with Input

Used to convert input from one data type to another.

### Integer Input

```python
age = int(input("Enter your age:"))
```

### Float Input

```python
marks = float(input("Enter your marks:"))
```

### Practiced

* Converting string to integer
* Converting string to float
* Checking data types using type()
